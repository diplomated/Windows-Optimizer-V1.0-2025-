**Windows Optimizer** — это мощный инструмент для оптимизации, настройки и очистки Windows 10/11. С современным интерфейсом на PyQt6, поддержкой тем (светлая/тёмная), и множеством функций для повышения производительности, безопасности и кастомизации. Всё работает по клику кнопки, без ручного ввода команд!

### Ключевые особенности ✨
- **Безопасность**: Управление обновлениями, фаерволом, антивирусом, отключение OneDrive и SmartScreen.
- **Оптимизация**: Твики для производительности, отключение телеметрии, управление службами, HPET, AI-оптимизация.
- **Очистка**: Удаление UWP-приложений (по выбору или все), очистка кэша, временных файлов, Prefetch и Recycle Bin.
- **Приложения**: Установка драйверов (NVIDIA, AMD, Intel), браузеров (Firefox, Chrome, Brave, Opera), приложений (Steam, Discord, VS Code, Spotify).
- **Кастомизация**: Установка инструментов (Rainmeter, PowerToys, ExplorerPatcher), смена тем, обоев.
- **Твики Windows**: Десятки безопасных оптимизаций (отключение Cortana, анимаций, фоновых приложений и т.д.).
- **Ресурсы**: Ссылки на чистые ISO Windows от Flibustier.

Приложение запускается с правами администратора для выполнения системных команд. Поддержка русского и английского языков в настройках.

### Установка 📥
1. Клонируйте репозиторий:
git clone https://github.com/yourusername/windows-optimizer.git

2. Установите зависимости:
pip install -r requirements.txt

3. Запустите файл:
python optimizer.py


**Требования**: Windows 10/11, Python 3.8+, Winget (для установки приложений, если не установлен — скачайте из Microsoft Store).

### Использование 🛠️
- **Интерфейс**: Вкладки для категорий (Security, Optimization, Cleanup, Apps, Customization, Windows Tweaks, Resources).
- **Настройки**: Переключение тем, автозапуск, очистка кэша по расписанию, выбор языка.
- **Предупреждения**: Для рискованных операций (например, отключение антивируса) показываются предупреждения.
- **Подпись**: Внизу интерфейса — "Soft by diplomat".

Некоторые изменения требуют перезагрузки системы для применения.
